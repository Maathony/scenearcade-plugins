# This repository is retired

This plugin is no longer used or updated, and the repository is kept read-only for reference.

AppAfterApp publishing now uses the AppAfterApp connector, which you add once to your AI app:

- Connector address: `https://appafterapp.com/mcp`
- How to add it (Claude and Codex): [AppAfterApp Docs, Connect your assistant](https://appafterapp.com/docs/docs-publish.html#connect-your-assistant)
- All Docs: <https://appafterapp.com/docs/docs.html>

If you installed this plugin, uninstall it and add the connector instead. The plugin's saved address no longer works.

Help: support@appafterapp.com
